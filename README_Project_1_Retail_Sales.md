## 📌 Project Overview
This project explores retail sales data through exploratory data analysis (EDA) and an interactive dashboard. The goal is to examine sales performance, purchasing patterns, and product trends, and present insights that can support business decisions.

## 🎯 Objectives
- Prepare and explore retail transaction data.
- Examine sales trends and customer purchasing behavior.
- Visualize findings through charts and an interactive dashboard.
- Communicate insights in a clear, accessible format.

## 🔧 Key Work
- Data cleaning and exploratory analysis
- Sales and customer-pattern visualization
- Interactive Streamlit dashboard development
- Dashboard deployment and recorded demonstration
