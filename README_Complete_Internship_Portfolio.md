**OIBSIP Level 1 — Task 1**

An exploratory data analysis (EDA) project examining retail transactions to understand sales performance, purchasing patterns, and product-category trends. Results are communicated through visualizations and an interactive dashboard.

### Objectives & Work
- Prepare and explore retail transaction data.
- Investigate sales patterns, customer behavior, and product trends.
- Communicate findings through clear visualizations.

## 🧠 Project 03 — Autocomplete & Autocorrect Using NLP

**OIBSIP Level 2 — Task 5**

### Overview
A natural language processing application trained using the **WikiText-2** text corpus. It combines statistical N-gram next-word prediction with edit-distance-based spelling correction, evaluates the methods, and makes them accessible through a Streamlit dashboard.

### Objectives & Work
- Clean and tokenize text; explore word-frequency distributions.
- Train **Bigram** and **Trigram** next-word prediction models with fallback suggestions.
- Implement autocorrect using **Levenshtein Edit Distance** and word-frequency-based candidate ranking.
- Evaluate autocomplete with **Precision@3** and **Recall@3**.
- Evaluate autocorrect accuracy and visualize results, including a confusion matrix.
- Deploy an interactive NLP dashboard for live demonstrations.

### Evaluation Highlights

| Metric | Result |
|---|---:|
| Bigram Recall@3 | 25.23% |
| Trigram with fallback Recall@3 | **27.48%** |
| Exact spelling correction accuracy | **91.67%** on 60 synthetic typos |

> **Evaluation note:** These are project-specific held-out next-word and synthetic-typo test results. They do not establish production-level accuracy or performance on real keyboard errors.

### Project Resources
- 🌐 **[Live Autocomplete & Autocorrect Dashboard](https://oibsip-autocomplete-autocorrect-nlpgit-fqebdpk5l7obck7jyqrxts.streamlit.app/)**
- 🎬 **[NLP Project Demo Video](https://drive.google.com/file/d/1bEOyAglaVUjX8ukrkgM-UkmOSGAdnW4O/view?usp=sharing)**
- 📚 **[WikiText-2 Dataset — Hugging Face](https://huggingface.co/datasets/Salesforce/wikitext)**

**Limitations:** N-gram models use limited context, while one-edit spelling correction may fail on multiple edits or context-sensitive real-word errors.

**Future scope:** Transformer-based language models, context-aware autocorrect, larger and more diverse corpora, personalization, and evaluation on real-world typing errors.

## ▶️ Running the Streamlit Applications Locally

For a project folder containing `app.py` and `requirements.txt`:

```bash
pip install -r requirements.txt
streamlit run app.py
```

For **Project 03**, also place the exported `model_artifacts.pkl.gz`, `summary_metrics.json`, and `top20_words.csv` alongside `app.py`. The confusion-matrix PNG is needed to display that image in the evaluation tab.

> Each project may have different dependencies or data-loading requirements; consult its folder-level README and source code.
