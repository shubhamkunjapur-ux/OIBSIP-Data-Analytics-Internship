## 📌 Project Overview
This project investigates customer characteristics and purchasing behavior to identify meaningful customer groups. An interactive Streamlit dashboard makes the analysis easier to explore and communicate.

## 🎯 Objectives
- Explore and preprocess customer data.
- Analyze customer characteristics and spending behavior.
- Present customer-segmentation insights through visualizations.
- Deploy an interactive dashboard for project demonstration.

## 🔧 Key Work
- Data preparation and exploratory data analysis
- Customer-behavior and segment analysis
- Interactive visualizations and dashboard development
- Deployment and recorded walkthrough
